How to use QuickView

QuickView is a monday.com Board View. It lists column and item IDs so you can copy them for automations, webhooks, and GraphQL. It does not draw badges on the Main Table.

1. Install

  1. Install QuickView from the monday Marketplace (or your share/install link).
  2. Approve the requested scope: boards:read.

2. Add the Board View

  1. Open any board.
  2. Next to Main Table, click + (Add view).
  3. Choose QuickView / your Board View feature.
  4. Open that view. The app only runs here.

3. Columns tab

  • Browse all column IDs on the current board.
  • Click a row to copy the column ID.
  • Sort by type or board order. Collapse type groups with the chevron.
  • Use Copy all IDs (TSV) or Copy JSON (id to name map).

4. Items tab

  • Search the whole board by name (server-side).
  • Paste a numeric item ID to look it up on this board.
  • Choose 25 / 50 / 100 per page and use Previous / Next.
  • Click a row to copy the item ID.

5. IDs on the board tab

Optional: link to the separate Chrome extension Monday Tools for Main Table header/item badges. The Marketplace Board View does not require the extension.
