1.2 What the App is

QuickView is a monday.com Marketplace Board View. After installation, users add it as a Board View on a board. The App lists column IDs and item IDs for the open board, supports search/pagination for items, and copy/export helpers (TSV / JSON).

The App is hosted as client-side code on monday.com CDN (“monday code” client hosting). We do not operate an application backend for QuickView.

1.3 Data we process

Through the monday.com SDK and API (seamless auth inside the monday iframe), the App may read:

  • Board identifiers and board names
  • Column identifiers, titles, and types
  • Item identifiers, names, group metadata, and subitem relationship flags
  • Board items_count for pagination labels
  • App context provided by monday.com (for example board id and locale-related context)

Preference data (language, column sort) may be stored with monday.storage.instance, which is monday.com account-scoped storage.

1.4 What we do not do

  • We do not require a user-provided monday API token.
  • We do not run our own database for board/item content.
  • We do not sell personal data.
  • We do not use App data to train AI models.
  • We do not request write scopes; the App uses boards:read only.

1.5 Legal bases / purpose

Data is processed solely to provide the App’s functionality inside monday.com: displaying identifiers, search, pagination, copy/export, and remembering UI preferences.

1.6 Sharing

Board and item data stay inside the monday.com session and the App iframe. Billing and subscription (if enabled) are handled by monday.com’s monetization framework. We do not share App content with unrelated third parties.

1.7 Retention

Because QuickView is client-side, board/item data is fetched when you use the App and is not retained on our servers. Preferences in monday storage remain until cleared by the platform or the user/account.

1.8 Security

Access is mediated by monday.com authentication and the App’s granted OAuth scopes. Transport uses HTTPS. No App secret exchange runs in the client for a custom backend because there is no QuickView backend.
